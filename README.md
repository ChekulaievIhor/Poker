# Hold'em NL

No-Limit Texas Hold'em: движок, боты, браузерный клиент и игровой сервер для игры по сети.

## Запуск

```
npm install
npm run build      # собирает сайт в dist/index.html
npm test           # движок + словари + сквозной тест сервера
```

- **С ботами** — работает везде, даже если просто открыть `dist/index.html` двойным кликом.
- **По сети** — вкладка «По сети» → «Создать стол». Появится ID стола из 6 символов (без похожих I/1, O/0).
  Друзья вводят ID или открывают ссылку-приглашение `адрес#ID` (кнопка с ID в шапке копирует её).

## Netlify (без своего сервера)

На Netlify игра работает целиком в браузерах — **сервер не нужен**:

- браузер того, кто создал стол, становится хостом стола (в нём крутится тот же движок, что и на сервере);
- остальные подключаются к нему напрямую по WebRTC; познакомиться браузерам помогает бесплатный
  сигнальный сервис PeerJS (`0.peerjs.com`), а при сложных сетях — его публичные TURN-серверы;
- камера и микрофон идут так же, напрямую между игроками.

**Выложить:** app.netlify.com → Add new site → Deploy manually → перетащить папку `dist`.
Или подключить репозиторий: `netlify.toml` уже настроен (`npm run build`, публикуется `dist`).
Netlify сразу даёт HTTPS-адрес — камера и микрофон работают.

Ограничения режима без сервера:

- **вкладку создателя стола нельзя закрывать** — вместе с ней закрывается стол (браузер переспросит);
- гость может перезагрузить страницу или потерять связь — он вернётся на своё место;
- хост технически может подсмотреть карты (они у него в браузере) — для игры на фишки с друзьями это нормально,
  для игры на деньги нужен сервер;
- статистика живёт, пока открыт стол.

Свой сигнальный сервер PeerJS можно указать в странице: `window.HOLDEM_PEER = { host, port, path, secure }`.

## Свой Node-сервер (по желанию)

Для хостингов с постоянными процессами (Render, Railway, Fly.io, VPS): `npm run build && npm start`
(порт из `PORT`, по умолчанию 8080). Сервер раздаёт сайт сам и подключает его к себе по WebSocket;
статистика сохраняется в файл. Стол не зависит от браузера создателя. Этот вариант понадобится для игры на деньги.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | 8080 | порт HTTP/WebSocket |
| `TURN_MS` | 30000 | время на ход |
| `NEXT_HAND_MS` | 4500 | пауза между раздачами |
| `STATS_FILE` | server/data/stats.json | где хранится статистика игроков |

Адрес сервера можно указать и вручную в лобби («Сервер» во вкладке «По сети»); пустое поле — режим без сервера.

## Структура

```
src/engine/            движок: колода, оценка рук, правила, банки, передача фишек
src/bots/bot.js        боты: эквити Монте-Карло + шансы банка + характер
src/i18n/              локализация: i18n.js + 36 словарей в locales/
src/ui/app.js          клиент: стол, анимации, таймер, журнал, лобби, карточка игрока
src/ui/local-table.js  игра с ботами в браузере
src/ui/net-table.js    сетевой клиент: протокол, переподключение (транспорт — WebSocket или P2P)
src/ui/p2p.js          игра без сервера: хост стола в браузере, подключение через PeerJS
src/ui/media.js        камера и микрофон (WebRTC «каждый с каждым»)
src/ui/ice.js          STUN/TURN-серверы для WebRTC
src/net/hub.js         логика сетевого стола — общая для Node-сервера и браузера-хоста
src/ui/avatars.js      процедурные SVG-аватарки по сиду
src/ui/style.css       стили, токены дизайна в :root
server/server.js       Node-сервер: HTTP + WebSocket вокруг hub.js
server/stats.js        статистика игроков (JSON-файл)
test/                  тесты
```

## Что умеет

- Полные правила NL Hold'em: блайнды, хедз-ап, мин-рейз, неполный олл-ин, сайд-поты, возврат неуравненной ставки.
- Таймер хода 30 с с кольцом вокруг аватарки; по истечении — чек, если можно, иначе фолд. В сети таймер считает сервер.
- Сервер — единственный источник правды: каждый игрок получает состояние «своими глазами», чужие карты не уходят на клиент до вскрытия (проверяется тестом).
- Переподключение: игрок с тем же токеном возвращается на своё место. Отключившийся пропускает раздачи, через 5 минут место освобождается.
- Свободные места можно занять ботами; когда приходит человек, а мест нет, бот уступает место.
- **Карточка игрока** (клик по аватарке): ник, сыграно раздач, процент побед, крупнейший банк, фишки за столом,
  передача фишек. Во время раздачи перевод ставится в очередь и выполняется после неё.
- **Камера и микрофон**: кнопки в шапке или в своей карточке. Видео заменяет аватарку. В карточке соперника можно заглушить его только для себя.
- **36 языков**: английский, немецкий, французский, испанский, каталанский, португальский, итальянский, нидерландский,
  польский, украинский, русский, белорусский, чешский, словацкий, словенский, хорватский, боснийский, сербский,
  македонский, болгарский, румынский, венгерский, греческий, албанский, турецкий, шведский, норвежский, датский,
  финский, исландский, эстонский, латышский, литовский, ирландский, мальтийский и арабский (с RTL-раскладкой).
  Язык определяется по браузеру, переключается в шапке. Переводы сделаны без носителей — перед релизом стоит дать вычитать.

### Добавить язык

1. Скопировать `src/i18n/locales/en.js` в `<код>.js` и перевести значения (ключи и `{параметры}` не трогать).
2. Добавить импорт и строку в `LANGS` в `src/i18n/i18n.js`.
3. `npm test` проверит, что ключи и параметры совпадают с английским.

## Протокол (JSON; по WebSocket `/ws` или по каналу WebRTC в режиме без сервера)

Клиент → сервер: `hello {token,name,avatar}`, `create {blinds,stack,bots}`, `join {tableId}`, `leave`,
`act {action}`, `transfer {to,amount}`, `profile {playerId}`, `media {cam,mic}`, `rtc {to,data}`.

Сервер → клиент: `welcome`, `joined {tableId,state}`, `event {ev,state}`, `state {state}`,
`clock {seat,remaining,total}`, `toast {key,params}`, `error {code}`, `timeout`, `rtc {from,data}`.

## Дальше по плану

1. Аккаунты (сейчас игрок узнаётся по токену в браузере) и база данных вместо JSON-файла.
2. Свой TURN-сервер (coturn) вместо публичных серверов PeerJS — для стабильного видео в сложных сетях.
3. Рост блайндов / турниры, анте, история раздач.
4. Новый дизайн стола: стили в `src/ui/style.css`, токены в `:root`.
5. Реальные деньги — отдельный этап: лицензия, KYC/AML, платёжный провайдер, сертификация ГСЧ.
   **Передачу фишек между игроками в режиме на деньги придётся отключить или жёстко ограничить** — это классический канал
   для отмывания и сговора (chip dumping), регуляторы это проверяют.
